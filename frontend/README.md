# Chest X-Ray ML Analysis Flutter App

 multi-platform Flutter application for chest X-ray analysis that works seamlessly across iOS, Android, macOS, Windows, and web platforms.



### Prerequisites

- Flutter SDK (3.9.2 or higher)
- Dart SDK
- CXC backend service running
- Configure .env 


### Run Application 
````
flutter run 
````

### Flutter code analysis 
````
flutter analyze
````
