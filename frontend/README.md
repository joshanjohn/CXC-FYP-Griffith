# Chest X-Ray Analysis Flutter App

A modern, multi-platform Flutter application for chest X-ray analysis that works seamlessly across iOS, Android, macOS, Windows, and web platforms.



### Prerequisites

- Flutter SDK (3.9.2 or higher)
- Dart SDK
- For iOS development: Xcode
- For Android development: Android Studio
- For Web: Chrome browser

### Installation

1. **Clone the repository** (if applicable) or navigate to the project directory:
   ```bash
   cd /final-year-project/frontend
   ```

2. **Install dependencies**:
   ```bash
   flutter pub get
   ```

3. **Run the app**:
   
   For Web:
   ```bash
   flutter run -d chrome
   ```
   
   For iOS Simulator:
   ```bash
   flutter run -d ios
   ```
   
   For Android Emulator:
   ```bash
   flutter run -d android
   ```
   
   For macOS:
   ```bash
   flutter run -d macos
   ```
   
   For Windows:
   ```bash
   flutter run -d windows
   ```
